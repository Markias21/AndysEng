- 2026-08-02 | **새 상단 탭 "📖 리딩" — VOA 지문 + 토플식 문제 + 요약·재진술.** 지문은 AI가 만들지 않는다: **GitHub Actions(`.github/workflows/voa.yml` 매일 05:00 KST)가 VOA Learning English RSS 6개 카테고리를 돌며 새 기사를 모아 `public/data/reading/`에 커밋**하고, 기존 `pages.yml`이 그 커밋을 배포하면 앱은 same-origin으로 읽는다. 이렇게 한 이유는 VOA가 CORS 헤더를 주지 않아 브라우저가 RSS·기사를 직접 못 읽기 때문이다(`curl -H "Origin: ..."`로 확인). CORS 프록시는 CSP에 외부 호스트를 열어야 하고 제3자 서비스에 의존하게 돼 버렸다. "America's Presidents" 피드는 U.S. History와 기사가 완전히 겹쳐 뺐다. `scripts/`와 `public/`은 배포 경계가 달라 카테고리 목록을 각자 들고 있고, 어긋남은 테스트가 잡는다. 곁들여 `.gitignore`의 `data/`가 `public/data/`까지 무시하고 있어 `/data/`(루트 한정)로 좁혔다.

  **학습 흐름은 한 화면 · 제출 한 번**(유저 결정): 지문 + 객관식 4~5문제 + 표현 빈칸 3~5개 + 문장 재진술 + 영어 요약을 함께 내고, 답하지 않은 문제는 **스킵**으로 처리한 뒤 종합 평가한다(실제 토플 리딩 섹션과 같은 구조). 문제 유형은 `features/reading/types.js`에 토플 iBT Reading 6유형(사실정보·부정사실·추론·수사적 의도·어휘·문장재진술)을 두고 매 지문 서로 다른 유형으로 출제한다. 빈칸은 새 로직 없이 `shared/cloze.js`/`cloze-view.js`를 그대로 재사용한다(글자당 칸·스페이스바 단어 이동·첫 글자 힌트 — 글쓰기·복습과 같은 조작감).

  **AI 호출은 딱 둘이고, 둘 다 좁혀 놨다.** (1) **문제 세트 생성 — 지문당 평생 1회.** `store.readingSets[articleId]`에 영구 캐시(사전 `dict`와 같은 방식, 백업·GitHub 동기화에 함께 실림). **객관식 정답 키를 함께 받아 두기 때문에 객관식·빈칸 채점은 100% 로컬**(`features/reading/score.js`, 순수 함수+테스트)이고 재도전은 AI 0회다. 빈칸의 영어 예문은 받지 않고 표현만 받아 `passage.js`가 지문에서 되찾는다(출력 토큰 절약). (2) **요약·재진술 채점 — 지문을 보내지 않는다.** (1)에서 받아 둔 `main_idea`+`key_points` 체크리스트만 보내고, `covered`는 항목 문구를 되돌려받지 않고 순서대로 불리언만 받는다(이 최적화만으로 채점 비용 $0.0370→$0.0317, 14%↓). **요약·재진술을 모두 비우고 제출하면 호출 자체를 하지 않는다(0원).** 채점 루브릭은 기존 4대 축을 쓰되 리딩 전용 절대 밴드 2개를 `shared/scoring.js`에 추가했다 — `READING_TASK_RUBRIC`(원문 충실도: 핵심 누락·사실 왜곡을 크게 감점하되 사소한 세부 생략은 감점하지 않음), `READING_RANGE_RUBRIC`(range를 "어휘가 화려한가"가 아니라 **원문을 베끼지 않고 자기 말로 바꿨는가**로 재정의 — 베껴 쓰기가 이 축의 최대 감점 사유). 배점 task 40·accuracy 20·range 20·fluency 20.

  **실측 비용**(헤드리스 크롬으로 실제 호출, `usage`에서 읽음): 문제 생성 ≈ **$0.039**(지문당 평생 1회) · 요약+재진술 채점 ≈ **$0.032**(매 시도) · 객관식·빈칸 채점과 캐시된 지문 재도전과 산출 스킵 = **$0** · 비교용 글쓰기 첨삭 1회 = **$0.052**. 즉 지문 한 편 완주는 처음 $0.071(글쓰기 첨삭의 1.4배), 두 번째부터 $0.032(0.6배), 이해 문제만 풀면 0원이다.

  기록은 `records.reading`에 남기고 통계·달력에 📖로 반영한다(유저 결정). 단 **요약·재진술을 모두 건너뛴 기록에는 `score`가 없어서**, `stats.summarize`/`dailyStats`가 점수 없는 기록을 평균에서 빼도록 방어했다. 번역기는 리딩에서 **-10점**(`TRANSLATOR_PENALTY.reading`) — 요약을 번역기로 쓰면 과제 자체가 사라지기 때문. 곁들여 사전·번역기 버튼을 `querySelectorAll` 일회성 바인딩에서 **이벤트 위임**으로 바꿨다(리딩은 툴바를 동적으로 그려 기존 방식으로는 동작하지 않는다). 표현은 다른 기능과 동일하게 자동으로 담지 않고 `못 맞힘` 배지만 달아 유저가 `➕`로 고른다.

  **구조화 출력 스키마 제약(발견):** Anthropic `output_config.format.json_schema`는 배열의 `minItems`(0·1 외), `maxItems`, `minimum`/`maximum`을 지원하지 않는다(`minItems values other than 0 or 1 are not supported` 오류). 개수는 `description`과 프롬프트로 지시하고, 4지선다·정답 인덱스 범위 같은 불변식은 `ai.js`가 응답을 받은 뒤 로컬에서 검증해 어긋난 문항을 버린다.
